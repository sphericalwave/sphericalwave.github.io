{%- comment -%} Fourthwall Storefront API, progressive enhancement, with a client-side cart. merch.md ships complete product cards. This upgrades the ones present in the live catalogue: real photos, colour and size pickers, the price for the exact variant, and an Add to cart button. The cart is a list of variant ids in localStorage. Fourthwall's checkout accepts several variants in one URL — /cart/checkout?products=:,:¤cy=CAD — so checking out is just building that link. No cart API, no backend, and nothing to keep in sync. Before this, each Buy button opened a checkout holding only its own item, so a second click replaced the first and anyone wanting two things paid shipping twice. Anything not upgradable is left alone: no token, failed request, product absent from the collection, everything out of stock. Without JavaScript each card still links to its product page on the shop. The storefront token is public and read-only by design. Payment happens on Fourthwall's checkout, never here. {%- endcomment -%} {%- assign shop = site.fourthwall_shop | default: site.store_url | default: "" -%} {%- assign token = site.fourthwall_token | default: "" -%} {%- if shop != "" and token != "" -%} {%- endif -%}
