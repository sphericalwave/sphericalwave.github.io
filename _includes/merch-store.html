{%- comment -%} Fourthwall Storefront API, progressive enhancement. The page already renders complete product cards from merch.md. This script upgrades them in place with live prices, sizes and stock, and turns each card's status chip into a Buy button that goes straight to Fourthwall's checkout. If the token is unset, the request fails, or a product is missing from the collection, the static card is left exactly as it was — so a bad API day costs the live prices, not the page. The storefront token is public by design (Fourthwall calls it ptkn_...); it only reads published catalogue data. Payment happens on Fourthwall's checkout, never here. {%- endcomment -%} {%- assign shop = site.store_url | default: "" -%} {%- assign token = site.fourthwall_token | default: "" -%} {%- if shop != "" and token != "" -%} {%- endif -%}
