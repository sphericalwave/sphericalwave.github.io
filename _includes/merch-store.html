{%- comment -%} Fourthwall Storefront API, progressive enhancement. merch.md already renders complete product cards. This script upgrades the ones it finds in the live catalogue: real photos, colour and size pickers, the price for the exact variant chosen, and a Buy button that goes straight to Fourthwall's hosted checkout. Anything it cannot upgrade is left alone — unset token, failed request, product missing from the collection, everything out of stock. A bad API day costs the live data, not the page. The storefront token is public and read-only by design (ptkn_...). Payment happens on Fourthwall's checkout, never here. {%- endcomment -%} {%- assign shop = site.fourthwall_shop | default: site.store_url | default: "" -%} {%- assign token = site.fourthwall_token | default: "" -%} {%- if shop != "" and token != "" -%} {%- endif -%}
